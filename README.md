# IniParser

Analisador léxico e sintático para arquivos .INI usando Python Sly

Implementação usando a biblioteca: [Sly](https://sly.readthedocs.io/en/latest/sly.html)

---

## Instalação

### 1. Clonar o projeto

    git clone https://github.com/fahadkalil/IniParser.git
    cd IniParser

### 2. Criar e ativar o virtualenv para o projeto

#### Windows (cmd)

      python -m venv .venv
      .venv/Scripts/activate.bat

#### Windows (PowerShell)

      python -m venv .venv
      .venv/Scripts/Activate.ps1

#### Linux / MacOS
  
      python -m venv .venv
      source .venv/bin/activate

---

### 3. Instalar dependências

    pip install -r requirements.txt

### 4. Rodar o projeto (com o venv ativado)

    python main.py
